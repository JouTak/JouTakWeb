# Безопасность аккаунта и название сервера

Локальная итерация 21.09.2026. Публикация и push не выполнялись.

## Интерфейс безопасности

На `/account/security` при включённом Community Hub разделены вход в аккаунт,
дополнительная защита, устройства и удаление. Нет дополнительной навигации,
анкеты профиля или декоративной оценки защищённости. Почта и её подтверждение,
состояние MFA и текущий сеанс видны сразу. Формы открываются рядом с действием;
при сворачивании секции введённое остаётся в памяти до ухода со страницы.

Связанные сервисы показывают состояние подключения; доступный сервис подключается
одной кнопкой. Возвраты `#linked` и `#mfa` открывают соответствующий раздел.
Список устройств показывает браузер, систему и активность; IP и полный user agent
перенесены в раскрываемые сведения. Сохраняется прежнее окно списка в 48 часов,
это явно подписано. Завершение сеанса требует подтверждения последствий,
а удаление аккаунта — прежнего пароля и контрольного слова.

Сервисы аутентификации, reauthentication, WebAuthn и recovery flows сохранены.
При ошибке чтения MFA не показывается ложное состояние «выключена» с предложением
настройки. После изменений MFA обзор получает актуальный статус. После смены
почты обзор показывает ожидающий подтверждения адрес. Ответы старого запроса
игнорируются при смене аккаунта; временная ошибка API не приравнивается к logout.

Логика legacy-персонализации при выключенном Hub-флаге сохранена. Новых API,
разрешений или зависимостей не добавлено.

## JouTak SMP

Публичное имя серверного сообщества теперь **JouTak SMP**. Миграция
`communities.0003_joutak_smp_name` меняет только стандартные имя и короткое описание
записи `itmocraft`. Сам slug, id, связи городов и членства сохраняются. Уже
отредактированный нестандартный текст миграция не заменяет. Reverse — noop:
откат схемы не должен незаметно возвращать старый бренд.

Совместимая команда `seed_itmocraft_community` создаёт JouTak SMP с прежним slug,
повторно не создаёт записи и не переписывает пользовательское описание. Старое
имя команды оставлено ради существующих скриптов. Исторические страницы ITMOcraft
и их маршруты не переименовываются этим изменением: запрос относился к серверному
сообществу Hub. В городских подсказках и пустом состоянии также указано JouTak SMP.

## Ручная проверка

1. Открыть локальный `/account/security` после обновления страницы. Проверить
   видимые статусы и отсутствие формы профиля.
2. Раскрыть пароль и привязки, свернуть и раскрыть снова. Открыть `#linked` напрямую.
3. Раскрыть дополнительную защиту, проверить сохранение доступности ключей и кодов.
   Не отключать реальные способы входа ради визуальной проверки.
4. Проверить подтверждение завершения другого сеанса, затем отменить. Текущий
   сеанс не должен меняться. Реальный logout тестировать только намеренно.
5. Открыть страницу на узком экране: карточки располагаются в одну колонку,
   действия устройств переносятся, горизонтальной прокрутки нет.
6. В `/communities`, аккаунте и городских связях увидеть JouTak SMP. Старые URL
   `/communities/itmocraft` продолжают работать.

Браузерные сценарии используют тестовые ответы API: проверяют адаптивность,
доступность, ошибку MFA и подтверждение отключения другого устройства без
изменения настоящих учётных данных. Перед локальной миграцией сохранена копия
`.local/backups/before-security-smp-20260921.sqlite3`.
