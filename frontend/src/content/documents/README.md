# Документы сайта

`manifest.json` задаёт заголовок документа, текущую редакцию и список доступных
редакций. У каждой редакции собственный Markdown-файл, автор, дата публикации
и дата обновления. В интерфейсе это элементы Gravity UI; оглавление строится
по заголовкам `##` и `###`.

## Новая редакция

1. Добавьте файл `<тип>/<YYYY-MM-DD>.md`. Для нескольких редакций в день можно
   использовать суффикс, например `2026-09-21.2`.
2. Добавьте запись в `versions` соответствующего документа: `id`, `author`,
   `publishedAt`, `updatedAt`, `file`. Даты указываются в формате `YYYY-MM-DD`.
3. Обновите `currentVersion`. Старые опубликованные файлы и записи сохраняйте:
   ссылки `/privacy-policy?version=2026-09-21` должны открывать прежний текст.
4. Проверьте `npm run check` и браузерный тест документов.

Поддерживаются CommonMark и GFM: заголовки, списки, таблицы, ссылки, цитаты,
код и сноски. HTML/JSX не исполняются. Основной заголовок задаётся в манифесте,
в тексте используйте `##` для разделов. Не переименовывайте опубликованные
заголовки без необходимости: от них зависят ссылки оглавления.

Тексты и метаданные первой редакции пока демонстрационные; при публикации
утверждённых документов добавьте новую редакцию с действительными данными.
